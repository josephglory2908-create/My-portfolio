Python · API integration · SQLite

Historical weather data pipeline

A PyCharm application designed to retrieve archived weather observations, calculate multi-year statistics, and store queryable results in a relational database.

Discuss this projectBack to portfolio
EnvironmentPyCharm
LanguagePython
SourceOpen-Meteo API
StorageSQLite & SQLAlchemy

01 / Objective

Turn archived weather observations into reusable analytical records.

The application targets Los Angeles, California and requests August 29 observations for 2018 through 2022. It is structured to summarize temperature, wind speed, and precipitation across the selected period.

02 / Application flow

API request to persisted result.

Open-Meteo API→Weather class→Calculations→SQLAlchemy ORM→SQLite

The workflow separates retrieval and calculation logic from database operations, with a main application module coordinating execution.

03 / Measures

Three weather dimensions, multiple summary statistics.

TemperatureAverage, minimum, maximum
Wind speedAverage, minimum, maximum
PrecipitationTotal, minimum, maximum

04 / Technical approach

Skills demonstrated

05 / Analytical value

A reusable pattern for external data pipelines.

The project demonstrates how to acquire external data, transform observations into meaningful measures, define a persistent schema, and retrieve stored records by location and date—an approach that can extend to reporting, monitoring, and operational analytics.
